# Отчёт по чистке рудиментов

- Дата: 2026-03-17
- Ветка: `feature/relay-aes-headless`
- Базовый commit: `829ef1b`

## Методология

1. Статический аудит ссылок (`rg`) по кандидатам рудиментов.
2. Сверка связей между слоями (DOM/renderer, preload/main IPC, server/client).
3. Точечное удаление подтверждённо неиспользуемых или недостижимых фрагментов.
4. Валидация: `node --check` для изменённых JS, повторный `rg` по удалённым идентификаторам.
